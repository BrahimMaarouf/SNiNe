# Concepts

## 1) NIST definition of cloud computing (5 characteristics, 3 service models, 4 deployment models)

### 5 characteristics

On-demand self-service, broad network access, resource pooling, rapid elasticity, measured service.

- **On-demand self-service:** consumer provision computing capabilities like server time, network storage, automatically without any human interaction with the provider.
- **Broad network access:** capabilities that are provided and available over network and accessed through standard mechanism that promote use thin or thick client platform like computer, phone, tablets, etc.
- **Resource pooling:** computing resources that are pooled to serve multiple consumers with dynamic physical and virtual resources and consumers have no idea about the exact location (but they can choose a higher level like country, region or datacenter) like storage, processing, memory, network bandwidth.
- **Rapid elasticity:** later
- **Measured service:** later

### 3 service models

- **SaaS:** Software as a service basically give the client applications to use with no option for client to deploy or control or manage anything, except some user settings inside the application.
- **PaaS:** Platform as a service here client can deploy application but it should be supported by the provider (languages, libraries, tools). The client controls the deployed application and some settings of the hosting environment, but can't manage the servers, network, OS or storage.
- **IaaS:** Infrastructure as a service here client can deploy any application and manage/control it + have can manage OS and many things.

**The 3 service models:** they all can't manage or control the cloud infrastructure, that means they can't manage the physical layer or the abstract layer.

- **Abstract layer:** is the software that manages the cloud physical resources and virtual machines.
- **Physical layer:** servers, storage, network bandwidth.

### 4 deployment models

- **Private cloud:** is a cloud infrastructure for exclusive use by one organization and not shared to the world, it can be managed by the organization or associates or third party.
- **Community cloud:** is a cloud infrastructure exclusive use to by a specific community of consumers from organizations.
- **Public cloud:** is a cloud infrastructure that are shared to any one.
- **Hybrid cloud:** is a cloud infrastructure where 2 or more infrastructures (private, community or public) stay separate but are connected, so data and applications can move between them (e.g. cloud bursting).
